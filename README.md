</div>

<br />

## Overview

Termix Identity is a built-in take on sshid.io. Claim a handle, publish your SSH public keys at a public URL, and issue SSH certificates from your own certificate authority.

<br />

## Features

- Publish your public keys under a handle
- Add your keys to any server with one command
- Generate new keys or import saved ones
- Your own SSH certificate authority

## Support

Found a bug or have an idea for Termix Identity? Open an issue in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Termix-Identity/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Termix-Identity/issues/new?template=feature_request.yml). The quickest way to report a bug is **Report an issue** on this plugin's page in the Termix Plugins tab, which fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Please be as detailed as possible, preferably in English. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
